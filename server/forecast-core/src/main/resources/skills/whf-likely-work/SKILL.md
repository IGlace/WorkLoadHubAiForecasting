# Likely work

Each member's `likely_work` holds `project_roles` (the member's share of each live project's assigned tasks over 26 weeks and their dominant task types there) and `recent_mix` (task-type counts over 13 weeks).

- Reason only from the project roles and the recent mix. Say "likely" or "probably", never "will".
- Confidence `medium` when a live project matches a role the member already holds (name the project key and share); `low` otherwise.
- When `project_roles` is empty, say that no live-project role is recorded and the expectation rests on the recent mix alone.
- At most four items per member, one sentence each, with the fact it rests on as evidence (a project key and share, or a type count).
